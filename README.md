## 关于原型

- 侧边栏沿用现网结构，本次只涉及「主数据管理 - 养殖池信息维护」，不新增菜单页
- 打开默认是列表页；点右上「导入」进入导入弹窗，再点「下载模板」查看模板预览
- 点表格任意一行「编辑」进入编辑弹窗（除「养殖池说明」外均置灰）
- 也可用 `index.html#import`、`#tpl`、`#edit` 直达对应弹窗
- 页面内为演示数据

## 本次调整

1. 支持导入养殖池
2. 编辑养殖池时仅允许编辑「养殖池说明」，其余字段置灰
3. 列表新增投苗编码、投苗日期、鱼种、当前存塘、可用预售
4. 列表字段顺序调整为：养殖池编码、养殖池名称、基地名称、车间名称、投苗编码、投苗日期、鱼种、当前存塘、可用预售、水深、面积、关联养殖户名称、创建人、创建时间、状态、操作
5. 支持按编码、鱼种、投苗日期筛选查询
